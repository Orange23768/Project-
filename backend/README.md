# Backend 
## Przeznaczenie 
Backend to część aplikacji działająca po stronie serwera.
Odpowiada za logikę biznesową, dane, bezpieczeństwo i komunikację.
Współpracuje z frontendem, który pokazuje użytkownikowi gotowy efekt.
Korzysta z języków programowania, baz danych i interfejsów API.
Ma kluczowy wpływ na wydajność, stabilność i skalowalność systemu.
Dobra znajomość backendu pomaga Ci lepiej rozumieć nowoczesne aplikacje.
## Komunikacja 
Backend udostępnia API i komunikuje się z bazą PostgreSQL. 
## Planowane endpointy - GET /api/tasks - POST /api/tasks - PUT /api/tasks/{id} - DELETE /api/tasks/{id}
